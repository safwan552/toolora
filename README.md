# Toolora

**Simple tools. Fast results.**

Toolora is a free collection of browser-based utilities for everyday tasks.

## Tools
- Image compressor, resizer, JPG ↔ PNG converters
- Merge PDF, split/extract PDF pages, JPG to PDF
- Word counter, case converter, whitespace cleaner, text repeater
- Password generator, QR code generator
- Percentage, age and basic calculators

## Privacy notes
Image and PDF utilities are designed to run locally in your browser. QR code generation uses an external service, so text entered for QR generation may be sent to that service. Avoid entering confidential information.

## Project
Built with Next.js, React, TypeScript and Tailwind CSS. See [project progress](PROJECT_PROGRESS_REPORT.md) for status.
